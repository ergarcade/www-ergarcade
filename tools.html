Tools

BLE utilities for the PM5 — for use at your erg, or for building your own applications.

pm5-detail User

Display every variable exposed by the PM5 over Bluetooth — more detail than the monitor shows.

Requires: Desktop, Chrome, Bluetooth
pm5-overlay User

Record a session with a live overlay of pace, stroke rate and more — built for coaching video.

Requires: Desktop, camera, Chrome, Bluetooth
c2log-overlay User

Turn a Concept2 logbook session into a video overlay of pace, SPM, distance, watts and cal/hr.

Requires: Desktop, Chrome
pm5-base Dev

Same PM5 variables as pm5-detail, stripped of interface — a starting point for your own app.

Requires: Desktop, Chrome, Bluetooth
pm5-dump Dev

Generate a JSON dump of all PM5 variables — handy as test fixtures during development.

Requires: Desktop, Chrome, Bluetooth

All applications on the Erg Arcade are open source — GitHub
