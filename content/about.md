Erg Arcade is a growing collection of browser-based tools, visual experiments,
and data analysis for [Concept2](https://www.concept2.com) ergometers - the
RowErg, SkiErg, and BikeErg. These applications talk directly to a [PM5
performance
monitor](https://www.concept2.com/indoor-rowers/performance-monitors) over
Bluetooth or USB, right from your browser, with no installs and no accounts.

It's a personal project, built for the fun of pulling live data off the erg and
doing something interesting with it - a second-screen display, a pace-driven
visualisation, a metric reporter for improving your skills, even games!

## Developers

If you're curious how any of this works, the source code for all applications is
available on [GitHub](https://github.com/ergarcade).

If you want to write your own browser-based applications, start with the
[pm5-base application](https://github.com/ergarcade/pm5-base), which contains
the code to talk to the PM5.
